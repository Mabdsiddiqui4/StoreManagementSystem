# 🏪 Store Management System (GUI Application)

A robust and reliable desktop application built with Java Swing to manage store inventories efficiently. The project is designed with solid Object-Oriented Programming (OOP) concepts, separating the graphical user interface logical data models.

## ✨ Key Features
- **Secure Data Entry:** Prevents application crashes (`NumberFormatException`) through intelligent text-trimming and empty-field validations.
- **Dynamic Product Storage:** Integrates a unified repository layout to add objects seamlessly into a centralized `ArrayList`.
- **Clean Interface Layout:** Formatted beautifully using advanced layout management (`GroupLayout`) for consistent multi-screen resizing.
- **Real-time Inventory View:** Allows checking the complete list of added products sequentially in a dedicated view panel.

## 🚀 How to Run the Project
1. Clone or download this repository onto your machine.
2. Open the project folder inside **NetBeans IDE**.
3. Locate the file `StoreForm1.java` within the `system` package.
4. Right-click the file and select **Run File** (or press `Shift + F6`).

## 🛠️ Built With
- **Language:** Java (JDK 11+)
- **Framework:** Java Swing & AWT
- **IDE Environment:** NetBeans Developer Tools
